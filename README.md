# Ironhold Remastered

A side-scrolling siege game: defend the gate against nightly skeleton hordes as the village blacksmith.

Play: https://miguelbraganca.github.io/ironhold/

- **Android:** open the link in Chrome and choose **Install app** (or ⋮ → **Add to Home screen**).
- **iPhone / iPad:** open the link in Safari, tap **Share** → **Add to Home Screen**, then open it from the new icon.

After the first load from the home-screen icon it works offline.
